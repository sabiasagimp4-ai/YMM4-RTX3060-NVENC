NVENC 出力と描画キャッシュの開発版です。v0.2.0-preview.2 からの変更は、不具合の修正、立ち絵とボイスのキャッシュ、GPU 保持と停止中の先読みの高速化です。基準ホストは YMM4 Lite 4.56.1.0 です。

## 不具合の修正

- キャッシュを有効にして初めて再生すると、保存するフレームごとに YMM4 の描画結果が 1 つずつ解放されずに残っていました（v0.2.0-preview.1／2）。長い区間を再生するとメモリと VRAM が増え続けます。次の描画で元の描画結果も解放するようにしました。
- ランダム移動などのランダム系がプロジェクトのどこかに 1 つでもあると、停止中の先読みが、ランダムと関係ない区間まで「複製と一致しない」として全部飛ばしていました。複製との比較では、オブジェクトの同一性の値だけを伏せて比べるようにしました（フレームのキーは今までどおり完全一致で比べます）。
- Community の CircularBlur は、直前に描いたフレームによって縁の絵が変わるため、自動の対象から外しました。その区間は YMM4 がそのまま描きます。
- HEVC の MP4 の設定（hvcC）を、エンコーダーが出した SPS から読むようにしました。読めない場合は壊れたファイルを出さずにエラーにします。
- 同じレイヤーで時間が重なるアイテムの区間は、通常描画にしました。YMM4 はアイテム一覧の順で重ねますが、その順をキーに入れていないため、順だけが変わると違う絵を出すおそれがありました。
- 停止中の先読みが、描いている間に消去された場合でも保存し得た点を直しました。

## 立ち絵（YMM4 4.56.1.0 同梱版）

- シンプル立ち絵、動く立ち絵（PNG の部品）、PSD 立ち絵を、キャッシュの対象にしました。口パクは、YMM4 自身が計算した音量の完了を確かめてから保存します。時間切れなどで口が閉じたまま描かれたフレームは保存しません。
- 動く立ち絵と PSD 立ち絵は、まばたきが起動ごとに変わるため、そのフレームをその起動の間だけ使います。起動し直すと、その区間は描き直しになります。
- 停止中の先読みは、動く立ち絵と PSD 立ち絵が映る区間を描きません（口パクの計算を再生に残すため）。その区間は、再生したときに保存します。シンプル立ち絵とほかの区間は先読みします。
- 同梱版以外、グループ・入れ子の中、動く立ち絵の PNG 以外の部品、表情が同じレイヤーで重なる場合などは、今までどおり YMM4 がそのまま描きます。

## ボイス

- ボイスの音声データ（4 KiB 以上）を、内容のハッシュでキーにするようにしました。CI の 50 ボイスでキーの元の文字数が約 97% 減りました。ボイスの多いプロジェクトで「対象外」（記述の上限）になりにくくなり、記述と編集後の回復も速くなります。

## GPU 保持

- 初めて描いて表示したフレームも、画素を確かめた後に GPU 上に残すようにしました。再生中は、余裕がある時だけ、次のフレームを RAM から 1 枚先に GPU へ上げます。
- VRAM の自動配分を、搭載 VRAM の 1/4 から 1/2（最大 8 GiB）に広げました。前の版の既定（自動・2048 MiB）のままの設定は、一度だけ Auto に移します。手動で選んだ上限は変えません。専用の VRAM がない内蔵 GPU では GPU 保持を使いません（RAM からの表示は使えます）。
- GPU が失われた（device lost）場合は、GPU に残したフレームをすべて捨て、通常描画から戻ります。

## 停止中の先読み

- 同時に描く描画器の数を選べるようにしました（ツール「描画キャッシュ」の「停止中の描画器」：Auto・1・2・4 本）。Auto は、コア数と VRAM から決め、GPU の使用量を測れるまでは 1 本です。ランダム系のフレームは、1 本目の描画器だけが描きます。

## ディスクキャッシュ

- ディスクの記録の形式を変えました（記録の名前と中身を結び付けて確かめます）。前の版のディスクキャッシュは使わず、描き直します。

## 制限

- 速さの数値は、GitHub Actions の Windows ランナー（Direct2D はソフトウェア描画の WARP）で測ったもので、RTX 3060 の値ではありません。
- 立ち絵の検査に使った素材は小さく、実際の大きな立ち絵（部品数百枚、100 MB 程度の PSD、PSB）や長時間の使用は、利用者の PC で確かめていません。
- 信頼設定した外部プラグインが、自分で持つ乱数（YMM4 のオブジェクトを種にしないもの）は追跡しません。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。NVIDIA GPU がないため、NVENC での実出力の検査は行っていません。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
