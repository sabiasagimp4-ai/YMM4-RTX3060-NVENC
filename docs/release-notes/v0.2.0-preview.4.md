YMM4 の古い版でも使えるようにした開発版です。v0.2.0-preview.3 からの変更は、YMM4 Lite 4.47.0.0 以降への対応と、YMM4 の版ごとの対応状況の自動確認です。4.56.1.0 での NVENC 出力と描画キャッシュの動きは変えていません。基準ホストは YMM4 Lite 4.56.1.0 です。

## YMM4 4.47.0.0 以降への対応

- v0.2.0-preview.3 までは、ビルドに使った YMM4 4.56.1.0 より古い YMM4 では、YMM4 が「必要なファイルを読み込めませんでした」と表示してプラグインを読み込みませんでした。.NET 10 で動く 4.47.0.0 以降の全版（54 版）で読み込めるようにしました。
- どの版でも NVENC 出力を使えます。描画キャッシュは、起動時に YMM4 のコードを照合し、4.56.1.0 と同じ部分だけを使います。
  - 4.56.1.0: すべて使います。
  - 4.56.0.0〜4.56.0.1: 口パクの完成判定、動く立ち絵、PSD 立ち絵、FFmpeg の動画のほかは使います。
  - 4.55.1.1: 選択枠、キャッシュバー、シンプル立ち絵、口パクの完成判定、動く立ち絵、PSD 立ち絵のほかは使います。
  - 4.47.0.0〜4.55.1.0: 描画キャッシュは使いません（YMM4 がそのまま描きます）。
- 4.54 より前の YMM4 には、書き出しで GPU 上のフレームを受け取ると知らせる仕組み（IVideoFileWriter3）がありません。その版では、それより前からある仕組み（IVideoFileWriter2）で GPU 上のフレームを受け取ります。
- 4.46.1.7 以前（.NET 8・9 で動く版）では、今までどおり読み込めません。

## 版ごとの対応状況の自動確認

- YMM4 の更新サーバーで公開されている全版（189 版）を YMM4 自身の更新と同じ手順で取得し、プラグインを入れて起動して確かめました。結果は README の表と [YMM4 の版ごとの対応](https://github.com/sabiasagimp4-ai/YMM4-RTX3060-NVENC/blob/main/docs/YMM4_VERSIONS.md) にあります。
- 毎日、新しい版が公開されたかを確かめます。公開されたら同じ確認をして表に書き足し、結果を Issue でも知らせます。

## 制限

- 版ごとの確認は GitHub Actions の Windows ランナーで行いました。NVIDIA GPU がないため、確かめたのは、YMM4 が起動し、プラグインが NVENC 出力の接続を確かめるところまでです。NVENC で実際に書き出す検査は行っていません。とくに 4.47.0.0〜4.53 で IVideoFileWriter2 から GPU 上のフレームを受け取る経路は、実機で書き出していません。
- 描画キャッシュの検査（画素の一致など）は、今までどおり 4.56.1.0 だけで行っています。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
