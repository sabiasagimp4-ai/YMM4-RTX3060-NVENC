NVENC 出力と描画キャッシュの開発版です。v0.2.0-preview.1 からの変更は、停止中の先読みの修正です。基準ホストは YMM4 Lite 4.56.1.0 です。

## 停止中の先読み

- ランダム移動・ランダム系のエフェクト（標準の RandomMoveEffect、Community の CameraShake など、YMM4 がオブジェクトを種にして乱数を決めるもの）が映るフレームも、停止中に先に描くようにしました。これまでは、複製したプロジェクトでは乱数が変わるため飛ばしていました。今回から、そのフレームだけは実物のプロジェクトを描く別の描画器で描き、実物のキーで保存します。描いている間に編集した場合、そのフレームは保存しません。
- ボタンを押さないマウスの移動を操作として数えないようにしました。これまでは、プレビューの上でマウスを動かすだけで先読みが中断し、待ち時間がやり直しになっていました。
- 複製すると状態が変わるフレームがあると、そこで毎回先読みが止まっていました。そのフレームを飛ばして先へ進むようにしました。ツールの表示に、飛ばしたフレームの数を出します。

## 診断

- 保存済みのフレームを初めて表示するときの時間の内訳（描画とGPUコピー）をトレースに記録するようにしました。保存時の描画が遅い件の調査に使います。

## 制限

- 信頼設定した外部プラグインが、自分で持つ乱数（YMM4 のオブジェクトを種にしないもの）は追跡しません。そのようなエフェクトは、複製で描いた乱数の値で保存され得ます。
- 立ち絵（口パク）が映るフレームは引き続きキャッシュしません。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。NVIDIA GPU がないため、NVENC での実出力の検査は行っていません。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
