古い YMM4 でも描画キャッシュを使えるようにした開発版です。v0.2.0-preview.4 からの変更は、YMM4 Lite 4.47.0.0〜4.56.0.1 での描画キャッシュ、描画器ごとに変わっていた乱数のそろえ込み、モザイクの修正です。基準ホストは YMM4 Lite 4.56.1.0 です。

## 古い YMM4 での描画キャッシュ

- v0.2.0-preview.4 では、4.55.1.0 以前は描画キャッシュを使わず、4.55.1.1〜4.56.0.1 も一部だけでした。4.47.0.0〜4.56.0.1 の 54 版について、4.56.1.0 との違いを読み、描画キャッシュの機能ごとに確かめた結果をプラグインに持たせました。起動時に YMM4 のコードを照合し、確かめたコードと同じ部分だけを使います（1 か所でも違えば、その機能は使いません）。
  - 4.56.1.0: すべて使います。
  - 4.55.0.0〜4.56.0.1: 立ち絵（シンプル立ち絵・動く立ち絵・PSD 立ち絵）と口パクの完成判定のほかは使います。
  - 4.47.0.0〜4.54.0.1: 上の版から、さらに選択枠を除いて使います。
- 版ごとの違いに合わせました: 4.54.0.1 以前のプレビュー（ズーム・パンがない）、文字の制御タグ（4.50 以前にはなく、4.51 は字間の指定がない）、停止中の先読み（4.49 以降。4.48 以前は先読みしません）、連番画像（4.56.0.0 以降）、Media Foundation の読み込み（新しい読み込みは 4.48 以降）。
- FFmpeg の動画（4.52.0.0 以降）: 4.54.0.0 以前の YMM4 には、シークした位置が要求した時刻よりずれたときにシークし直す処理がありません。そこで、シークした直後のフレームは、その次のフレームを読むまで保存しません（すべての版で同じ扱いです）。実際の YMM4 で、シークを繰り返して描いたフレームのうちキャッシュから出したものは、すべて先頭から順に描いた絵と一致しました。4.54.0.0 の MPEG-TS（.m2ts など）は、YMM4 自身がシーク後に違うフレームを描くことが多く、どのフレームも保存しません。

## 描画器ごとに変わっていた乱数をそろえる

- YMM4 は一部の乱数を、描画する処理のオブジェクト自身から決めています。プレビュー・書き出し・停止中の先読みはそれぞれ別の描画器なので、同じプロジェクトでも違う値になり、これまではその区間を描画キャッシュの対象外にしていました。
  - 4.52.0.1 以前のランダム系エフェクト（ランダム移動・回転・拡大・不透明度・傾き）。4.52.0.2 以降の YMM4 は、エフェクト自体から決めています。
  - テキスト・字幕を「ランダム」の順で表示・非表示にするとき（全版）。アイテムが画面に入り直すたびに描画器が作り直されるので、YMM4 だけでは入り直すたびに順が変わります。
- プラグインは、これらをエフェクト・アイテム自体から決めるように置き換えます（ランダム系エフェクトは、4.52.0.2 と同じ計算になります）。値の乱雑さは変わりません。プレビュー・書き出し・先読みが同じ値を描くので、描画キャッシュを使えます（他の同一性の乱数と同じく、その起動の間だけ）。実際の YMM4 で、2 つ目・3 つ目の描画器が 30 フレームすべて同じ絵を描くことを確かめました（4.51.0.3 では、以前は 30 フレームすべてが違っていました）。
- 動きが変わる点: このプラグインを入れると、ランダムの順で表示する文字は、アイテムが画面に入り直しても同じ順になります。また、書き出しはプレビューで見たのと同じ順・同じ動きになります。描画キャッシュを使える版では、キャッシュの設定のオン・オフにかかわらずこの扱いになります。

## モザイクの修正

- ドロネー・ボロノイのモザイクは、パラメーターのオブジェクトから乱数を決めて模様を作ります。これを描画キャッシュのキーに入れていなかったため、停止中の先読み（プロジェクトの複製で描きます）が違う模様のフレームを保存することがありました（4.56.1.0 を含む全版）。そのアイテムの起動中のオブジェクトをキーに入れ、先読みでは実物のシーンで描くようにしました。

## 制限

- 描画キャッシュの検査（実際の YMM4 での画素の一致など）は、GitHub Actions の Windows ランナー（WARP）で、代表的な版（4.47.0.0、4.51.0.3、4.52.0.0〜4.52.0.2、4.53.0.4、4.54.0.0〜4.54.0.1、4.55.1.1、4.56.0.1、4.56.1.0）について行いました。そのほかの版は、コードの照合と起動の確認です。
- NVIDIA GPU がないため、NVENC で実際に書き出す検査は行っていません。
- 立ち絵の描画キャッシュは、今までどおり 4.56.1.0 の同梱版だけです。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
