NVENC 出力と描画キャッシュの開発版です。前回（v0.1.0-preview.1）からの主な変更は次のとおりです。基準ホストは YMM4 Lite 4.56.1.0 です。

## 描画キャッシュ

- 標準プレビュー（再生・一時停止・シーク）と動画出力で、描き終えたフレームを RAM・ディスク・GPU に保存し、同じフレームをもう一度描くときに再利用します。設定は「プレビュー」「動画出力」で別々に ON／OFF でき、新規インストールでは両方 OFF です。
- キーはフレームごとに作ります。編集したアイテムの区間だけが描き直しになり、Undo で元に戻すと保存済みのフレームを再利用します。
- 動画のデコードが要求した時刻まで終わったと確かめられないフレームは保存しません。
- 停止中は、最後の操作から既定 8 秒後に、指定範囲（既定はタイムライン全体）を少しずつ先に描きます。
- RAM と VRAM は空きに合わせて自動で配分します。RTX 3060 以外の NVIDIA GPU にも対応しました。
- 自動でキャッシュの対象になるものを増やしました。連番画像、フォント（代替フォントを含む）、Community の処理（約 70 種）が対象です。詳しくは [自動対象の範囲](https://github.com/sabiasagimp4-ai/YMM4-RTX3060-NVENC/blob/main/docs/AUTOMATIC_COVERAGE_2026-10-03.md) を参照してください。

## NVENC 出力

- 失敗・取消のときに書きかけのファイルを残さないようにしました。出力設定は次回も保持します。

## 制限

- 立ち絵（口パク）が映るフレームはキャッシュしません（毎回通常どおり描きます）。対応は調査中です。
- 外部プラグインの処理、DirectShow で読む動画、残像・モーションブラーなどが映る区間も通常描画です。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。そこには NVIDIA GPU がないため、NVENC での実出力の検査（`build.ps1 -Smoke`）は行っていません。RTX 3060 での実機確認は前回のリリースまでです。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
