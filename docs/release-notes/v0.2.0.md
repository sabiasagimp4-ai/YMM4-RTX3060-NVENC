立ち絵とアイテムの重なりを描画キャッシュの対象に広げた版です。v0.2.0-preview.5 からの変更は、同じレイヤーで重なるアイテム、グループ制御・合成グループ・シーンアイテムの中の立ち絵、差分合成、同じレイヤーで重なる表情、付属 INI、まばたき、停止中の先読み、古い YMM4 での立ち絵、再生中・シーク時の先回りの描画です。基準ホストは YMM4 Lite 4.56.1.0 です。

## 同じレイヤーで時間が重なるアイテム

- YMM4 は、描く順のキー（常に手前・Z・レイヤー）が同じアイテムを、描画器の内部の辞書の順で重ねます。この順は先読みやシークの履歴で変わるので、YMM4 自身が描くたびに違う順で重ね得ます。これまでは、その区間を描画キャッシュの対象外にしていました。
- プラグインは、この順が決まっていない部分だけをアイテム一覧の順にそろえます（YMM4 が決めている順は変えません）。プレビュー・書き出し・停止中の先読み・合成グループやシーンの内側のどの描画器でも同じ順になり、その順をキーに入れるので、描画キャッシュを使えます。アイテム一覧の順を入れ替えると、重なる区間だけ描き直します。
- 通常の編集では、YMM4 がアイテムを別のレイヤーへずらすので、同じレイヤーのアイテムは重なりません（追加・移動・Alt を押しながらの複製・フレームレートの変更のどれでも）。重なるのは、プラグインやスクリプトがアイテムを直接置いた場合などです。
- 動きが変わる点: そうして重なったアイテムは、このプラグインを入れると、いつもアイテム一覧の順（後から追加したものが上）に重なります（描画キャッシュを使える版では、キャッシュの設定のオン・オフにかかわらず）。

## 立ち絵

- グループ制御・合成グループ・シーンアイテムの中、トランジションの前後の立ち絵（シンプル立ち絵・動く立ち絵・PSD 立ち絵）を対象にしました。非表示のレイヤーに動く立ち絵・PSD 立ち絵があるフレームも、ほかの部分は対象になります（これまでは通常描画でした）。合成グループやシーンの内側の描画器までたどって、口パクの完成や素材の状態を確かめてから保存します。
- 差分合成（動く立ち絵）を対象にしました。
- 同じレイヤーで重なる表情を対象にしました。YMM4 と同じくアイテム一覧の順で表情を選び、その順をキーに入れます。
- 付属 INI（動く立ち絵のパーツごとの合成設定 `X.ini`）を対象にしました。INI を依存に入れ、描画器の設定が今の INI を読み直した値と同じときだけ保存します（YMM4 は前に読んだ INI の値を残すことがあり、また数値を実行中のカルチャで読むため、そうした場合は通常描画にします）。
- まばたき（動く立ち絵・PSD 立ち絵）: YMM4 はまばたきの時刻を、素材のパスの、起動ごとに変わるハッシュから決めます。プラグインはこれを起動に依らないハッシュに置き換えるので、まばたきの時刻が毎回同じになり、再起動後もディスクのキャッシュを使えます（これまではその起動の間だけでした）。
- 停止中の先読みで、動く立ち絵の区間も描くようにしました。ただし、そのキャラのボイスが重なるフレームは、口パクの計算を再生に残すため描きません。PSD 立ち絵は、先読みの描画器が PSD をもう一つ丸ごと読み込んでしまうため、今までどおり再生したときに保存します。
- 古い YMM4: シンプル立ち絵は 4.54.0.1 以降、動く立ち絵・PSD 立ち絵は 4.55.1.0 以降で使います。立ち絵のコードを 4.56.1.0 と比べて確かめました（4.55.1.x の違いは編集画面の部品、4.56.0.x の口パクの違いは極端な再生速度での上限だけ）。4.55.0.x とそれ以前の動く立ち絵・PSD 立ち絵、4.54.0.0 以前のシンプル立ち絵は、口パクの音量の読み方や表情の画像の選び方が違うため使いません。

## 先回りの描画（これまでの「停止中の先読み」）

- 再生中も描くようにしました。再生位置の少し先から前へ描き、再生がすぐ描くフレームは再生に任せます。
- シークすると、待たずに新しい位置から描き直します。
- プレビューが変わらない操作（アイテムの選択、スクロール、メニューなど）では止まらなくなりました。止まるのは編集したとき（と YMM4 が処理中のとき）だけで、編集の後の待ち時間は既定 1 秒（これまでは操作の後 8 秒）、0.1 秒から選べます。
- 描画器は YMM4 より低い優先度で動くようにしました。

## 検査

- 実際の YMM4 で、キャッシュから出した画素が通常描画と一致することを、4.56.1.0 と、4.56.0.1・4.55.1.1（動く立ち絵・PSD 立ち絵を含む）・4.54.0.1（シンプル立ち絵）で確かめました。同じレイヤーで重なるアイテムは、シークの順を変えても、描画器を作り直しても同じ画素になること、一覧の順を入れ替えると絵とキーが変わることを確かめました。

## 制限

- 動く立ち絵の動画の部品と、他の作者の立ち絵プラグインは、今までどおり通常描画です。
- 描画キャッシュの検査は、GitHub Actions の Windows ランナー（WARP）で行いました。NVIDIA GPU がないため、NVENC で実際に書き出す検査は行っていません。
- このパッケージは GitHub Actions の Windows ランナーでビルドしました。

## インストール

1. YMM4 を終了します。
2. 添付の `YMM4-RTX3060-NVENC.ymme` を開き、YMM4 へインストールします（SHA-256 のファイルも添付しています）。
3. YMM4 を起動し、短い区間で表示・映像・音声・同期を確かめてから使ってください。
